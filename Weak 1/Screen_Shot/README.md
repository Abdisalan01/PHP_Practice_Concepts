
### 01-php-basics.php

This  covers the basic PHP concepts:

- Echo
- Variables
- Data Types
- Arithmetic Operators

Example:

```php
$name = "Abdisalan Hassan Omar";
$age = 25;

echo "Name: $name, Age: $age";
```

Arithmetic operators:

```php
$a = 10;
$b = 5;

echo $a + $b;
echo $a - $b;
echo $a * $b;
echo $a / $b;
echo $a % $b;
```

### 02-comparison-and-conditional-statements.php

This  covers:

- Comparison Operators
- var_dump()
- If Statement
- If Else Statement
- If Elseif Else Statement

Example:

```php
$x = 10;
$y = 20;

var_dump($x == $y);
var_dump($x != $y);
var_dump($x > $y);
var_dump($x < $y);
```

Conditional statement example:

```php
$number = 10;

if ($number > 5) {
    echo "Number is greater than 5";
} else {
    echo "Number is 5 or less";
}
```
